# Proyecto de Aplicación Web - Módulo I

## Metodología de Desarrollo en V (Rama Descendente)

Para el desarrollo de este proyecto, se ha implementado la metodología de desarrollo en V, centrándonos inicialmente en la **Fase de Verificación** (rama descendente). Este proceso asegura que cada etapa de construcción esté basada en una definición previa y clara.

### Etapas de la Fase Descendente:

1. **Análisis de Requisitos (Requirement Gathering):**
   En esta etapa se definieron las necesidades del usuario final y las funcionalidades esenciales que el sistema debe cumplir para ser exitoso.
2. **Análisis del Sistema (System Analysis):**
   Se definió el comportamiento general del software, estableciendo cómo interactúan los datos y la arquitectura funcional del sistema.
3. **Diseño de Software / Arquitectura (Software Design):**
   Se seleccionó el stack tecnológico (Python, Django, Docker, Vite.js) y se definieron los componentes principales y las interfaces de comunicación.
4. **Diseño de Módulos (Module Design):**
   Se detalló la lógica interna de cada módulo, definiendo los modelos de datos y los algoritmos necesarios para la ejecución de las tareas.

**Punto de Inflexión:** Una vez completadas estas etapas, se procede a la **Codificación**, que es la construcción real del código fuente basada en los diseños anteriores.
